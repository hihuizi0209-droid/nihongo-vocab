# 词语间 · 日语 N5–N3 冲刺版

免费 PWA 日语词汇学习工具。默认每天新增 80 个词，先采用日语→中文快速识别，再做当天快速复测和到期复习。

## 完整词库
首次联网打开时，网站会从 OpenJLPT 自动载入 N5、N4、N3 词汇并保存到当前浏览器。词库规模约 2,963 个词条（具体数量以数据源当前版本为准）。新词先按等级 N5 → N4 → N3，再按初步主题类别排列。

- 来源： [OpenJLPT](https://github.com/evanclan/OpenJLPT)
- 许可：CC BY-SA 4.0；JLPT 等级来自社区词表，不是 JLPT 官方固定词汇清单。
- OpenJLPT 提供英文释义、读音、词性及部分例句。卡片翻面时会尝试使用 Google Translate 的非官方接口把英文释义翻译为中文；翻译可能失败或有误，中文释义与用法尚未逐条人工复核。若翻译失败会显示英文原释义。
- 首次载入完整词库需要联网；载入后词汇会保存在当前浏览器本地。

## 冲刺复习规则
- 忘记：约 10 分钟后重现，并在本轮后续卡片中尽量再次出现
- 困难：1 天后
- 记住：1、3、7、14、30、45、60、90 天等递增间隔
- 轻松：7、14、30、60、90 天等递增间隔
- “当天快速复测”会打乱当天已学习的卡片，忽略到期日进行抽测

规则是适用于快速覆盖的简化调度，不是 Anki FSRS。学习记录保存在当前浏览器本地，跨设备不会自动同步。

## 更新到 GitHub Pages
把 `index.html`、`manifest.webmanifest`、`icon.svg`、`sw.js` 上传到 GitHub 仓库根目录并提交更改。刷新网站后，浏览器会安装新的 Service Worker 并在首次联网时加载完整词库。

## 安装到手机主屏幕
将整个文件夹发布到 HTTPS 静态托管（例如 GitHub Pages 或 Cloudflare Pages），打开站点后：
- iPhone：Safari → 分享 → 添加到主屏幕
- Android：Chrome → 菜单 → 安装应用/添加到主屏幕

本地 HTML 可直接打开体验，但 PWA 安装和离线缓存通常需要 HTTPS 或 localhost。
